# Servicing policy

Rules from Loan Operations that the code must enforce.

## Hardship deferrals

- A deferral pauses payments for **1 to 3 months**. Anything longer is a loan modification, which Loan Operations handles outside this system.
- Accepted reasons: medical hardship, job loss, natural disaster.
- Every request names the servicer who made it and is written to the audit trail before anything is saved.
